## What's New in v3.0

### Simplified CLI

20+ commands reduced to **10 focused commands**:

```bash
# PRIMARY COMMANDS
obs                        # List your vaults
obs stats <vault>          # Show vault statistics
obs discover <path>        # Find vaults in directory

# GRAPH ANALYSIS
obs analyze <vault>        # Analyze vault graph metrics

# AI FEATURES (optional)
obs ai status              # Check provider status
obs ai setup               # Interactive setup wizard
obs ai test                # Test all providers
obs ai similar <note_id>   # Find similar notes
obs ai analyze <note_id>   # Analyze a note with AI
obs ai duplicates <vault>  # Find duplicate notes

# UTILITIES
obs help                   # Show simple help
obs help --all             # Show all commands
obs version                # Show version
```

### Code Reduction

- **Before**: ~11,500 lines across 20+ commands
- **After**: ~7,400 lines across 10 commands (36% reduction)

## Core Features

### Vault Discovery

Automatically find and register Obsidian vaults by scanning for `.obsidian` directories.

```bash
obs discover ~/Documents
obs discover ~/Library/Mobile\ Documents/iCloud~md~obsidian/Documents
```

### Graph Analysis

Analyze your vault's knowledge graph structure:

- **PageRank** — Note importance based on link structure
- **Centrality** — Betweenness, closeness, degree metrics
- **Clustering** — Identify topic clusters
- **Orphan Detection** — Find unlinked notes
- **Hub Detection** — Find highly connected notes
- **Broken Links** — Detect wikilinks pointing nowhere

```bash
obs analyze MyVault
obs analyze MyVault -v   # Verbose with top hubs
```

See the [Graph Analysis Tutorial](tutorials/graph-analysis.md) for a deep dive.

### Rich CLI Output

Beautiful terminal output powered by Rich:

- Color-coded tables and stats
- Progress bars for long operations
- Emoji indicators for quick scanning
- Verbose mode (`-v`) on every command

## AI Features

Multi-provider AI for advanced vault analysis. All AI features are **optional** — obs works perfectly without them.

### Supported Providers

| Provider | Speed | Quality | Privacy | Cost |
|----------|-------|---------|---------|------|
| `gemini-api` | Fast | High | Cloud | API key |
| `gemini-cli` | Medium | High | Cloud | Free |
| `claude-cli` | Medium | Highest | Cloud | Free |
| `ollama` | Slow | Good | Local | Free |

### AI Commands

| Command | What It Does |
|---------|-------------|
| `obs ai status` | Check which providers are available |
| `obs ai setup` | Interactive setup wizard |
| `obs ai test` | Test provider connections |
| `obs ai similar <note_id>` | Find semantically similar notes |
| `obs ai analyze <note_id>` | Deep analysis: topics, themes, suggestions |
| `obs ai duplicates <vault>` | Detect potential duplicate content |

See the [AI Features Tutorial](tutorials/ai-features.md) for setup and usage.

## Architecture

### Three-Layer Design

```
Presentation → Application → Data
    (CLI)        (Core Logic)   (DB/Files)
```

- **Presentation**: `obs.zsh` — ZSH CLI wrapper (386 lines)
- **Application**: `vault_manager.py`, `graph_analyzer.py` — Core logic
- **Data**: `db_manager.py`, `vault_scanner.py` — SQLite + file I/O

### Technology Stack

- **ZSH**: CLI interface with fast shell integration
- **Python 3.9+**: Core logic (~3,500 lines)
- **SQLite**: Local knowledge graph database
- **NetworkX**: Graph analysis algorithms
- **Rich**: Terminal output formatting
