# Release Notes v3.0.0

**Release Date:** 2026-03-05
**Previous Release:** v2.2.0 (2025-12-20)

## Overview

v3.0.0 is a major release that transforms Obsidian CLI Ops into a laser-focused vault management tool with AI-powered graph analysis. The codebase was simplified from 11,500 to ~7,400 lines (36% reduction) while adding powerful new capabilities.

**Philosophy:** "Do one thing exceptionally well — manage Obsidian vaults."

## What's New

### Simplified CLI (Phase 7.1)

- **20+ commands → 15 focused commands** — eliminated feature overlap with other tools
- **ZSH-First Architecture** — fast shell integration with Python core
- **Removed TUI** (1,701 lines) — CLI-only for simplicity and maintainability
- **Removed R-Dev integration** (307 lines) — belongs in R package ecosystem
- **Removed legacy v1.x commands** (126 lines) — plugin install, sync, audit

### Multi-Provider AI System (Phase 7.2)

- **5 AI providers**: Gemini API, Anthropic API, Ollama, Gemini CLI, Claude CLI
- **Smart routing**: auto-selects best provider for each operation type
- **Modern SDKs**: migrated to `google-genai` (replacing deprecated `google-generativeai`), added `anthropic` SDK
- **Shared models**: `AnalysisResult`, `ComparisonResult`, `SimilarNote` dataclasses with `from_json()` validation
- **Embedding cache**: SQLite-backed `note_embeddings` table with mtime invalidation
- **Retry with backoff**: exponential backoff decorator on all API methods
- **Obsidian CLI bridge**: integrates with Obsidian's native CLI for backlinks and orphan data

#### New AI Commands

| Command | Description |
|---------|-------------|
| `obs ai suggest-links <note>` | Find unlinked related notes using embeddings |
| `obs ai gaps <vault>` | Detect stub notes, orphans, and knowledge gaps |
| `obs ai summarize <vault>` | Generate theme analysis across entire vault |
| `obs ai refactor <vault>` | AI-powered vault reorganization suggestions |

### Vault Health Dashboard (Phase 7.3)

- **`obs health <vault>`** — comprehensive health scores with 4 dimensions:
  - **Connectivity** (orphan ratio)
  - **Link Integrity** (broken link count)
  - **Structure** (tag coverage, hub balance)
  - **Freshness** (stale note detection)
- **Rich progress bar visualization** in terminal
- **`--json` flag** on all 10 data-outputting commands for scripting

### Vault Name/Prefix Lookup

- **Use vault names directly**: `obs analyze Knowledge_Base` instead of hex IDs
- **Prefix matching**: `obs analyze e947` resolves to the matching vault
- **Ambiguous prefix feedback**: clear error when multiple vaults match

### CLI Polish

- **`--verbose` flag** wired to all AI commands (suggest-links, gaps, summarize)
- **Better error messages** with tips: "Run 'obs discover <path>' to find new vaults"
- **Version consistency** enforced across 5 files via automated tests

## Breaking Changes

### Removed Commands

| Removed | Replacement |
|---------|-------------|
| `obs switch <vault>` | Use `obs analyze <vault>` directly |
| `obs open`, `obs sync` | Use Obsidian app directly |
| `obs tui` | Removed — CLI-only interface |
| `obs r-dev *` | Use R package tools directly |
| `obs install`, `obs audit` | Removed — v1.x legacy |

### Configuration Changes

- `textual` dependency removed (was required for TUI)
- `google-generativeai` replaced by `google-genai` (Gemini SDK migration)
- `anthropic` added as optional dependency

### Migration

See [Migration Guide](../migration.md) for step-by-step upgrade instructions from v2.x.

## Technical Details

### Architecture

```
Presentation (obs.zsh, 386 lines)
        ↓
Application (core/, 931 lines)
        ↓
Data (db_manager, scanner, ai/, schema)
```

**AI Router priority**: gemini-api > anthropic-api > ollama > gemini-cli > claude-cli

### Test Suite

- **186 tests** passing (pytest)
- **30 JS tests** (Jest, ZSH wrapper validation)

- **Coverage**: Python coverage reporting via `pytest-cov`

### Dependencies

- python-frontmatter, PyYAML, networkx, rich, requests, click

**Optional AI:**
- `google-genai>=1.0.0` (Gemini API)
